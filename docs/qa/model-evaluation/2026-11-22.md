# 2026-11-22 多角色真機回覆評測

本次只讀取校機現有服務，沒有部署、重啟或修改遠端程序。測試經 SSH tunnel 呼叫正式 `/generate`，每個案例重複生成三次，目的是找出「偶爾才出現」的人格、語言與知識邊界漂移。

## 執行時服務狀態

`/health` 顯示正在執行的 gateway 只有下列專屬路由：

- `vidalia → vidalia-lora`
- `menmesvento → menmesvento-lora`
- 其他已登記角色退回 `Qwen/Qwen2.5-7B-Instruct-AWQ`
- 艾倫與維塔尚未被這個舊 gateway 登記，請求回 HTTP 422

這不會推翻 2026-11-20 曾完成的六模型整合紀錄，但代表「目前正在執行的服務」已不是當時的六 adapter 狀態，不能宣稱現在六或八模型都 ready。

校機磁碟上八個最終 adapter 目錄都存在，且各有一份約 161.5 MB 的 `adapter_model.safetensors`，所以模型確實已訓練落地。`rag-npc-llm` Docker 容器也存在並掛載同一個 repo，但容器內只有兩個閒置 `bash`、沒有 port mapping，也沒有 vLLM／gateway 程序。實際提供 8000／8001 的服務是 host 上的 `.venv-gpu` 程序，啟動參數只有兩個 `--lora-modules` 且 `--max-cpu-loras 2`。缺口是服務載入設定，不是權重遺失或尚未訓練。

## 本輪新增的判斷

31 個案例覆蓋八位角色，每位至少三種情境，包括自介與地點、核心動機、挑釁、未確認設定、跨 NPC 私人記憶、假道具、假場景／結局與合理下一步。評測器現在支援：

- `--samples-per-case` 重複生成，揭露非固定的偶發漂移。
- `--npc`、`--case` 篩選角色與題目。
- `--require-dedicated-adapters` 將 base fallback 明確判為未達模型發布標準。
- 檢查 Traditional Chinese、必要概念群組、禁用設定、Markdown／meta 文字與未授權事件。

重跑六位現況服務：

```bash
PYTHONPATH=. ./.venv/bin/python scripts/evaluate_npc_gateway.py \
  --url http://127.0.0.1:8800/generate \
  --samples-per-case 3 \
  --npc andre --npc dasso --npc seth --npc syra \
  --npc vidalia --npc menmesvento \
  --require-dedicated-adapters
```

## 遊戲劇情安全結果

新增四種模型假回覆測試，包括「已獲得裂隙地圖」、「地圖已交付」、「邊境結果已成立」與「可直接進入圖書館」。非法事件被後端拒絕時，相關模型台詞也會一起隱藏；玩家仍看到原本三個邊境決策與返回選項。只有玩家正式選擇 `border_help_both` 後，背包才取得 `fissure_map`，故事節點才前進。

因此目前可確認的是：規則式主線仍能合理前進，模型不能越權代選故事；但角色模型內容尚未達到八位正式發布標準。
