完整走過：維達利亞交談 → 符石林 → 風沙線索 → 流塵谷 → 記下名字 → 返回議會 → 重整承接。調查結束後可再次探索另一條既有路線。地圖遠處追蹤會從 z=8 步行到約 z=-4.891，靠近後顯示出發選項，不直接傳送。

地圖開啟時連續按 30 次 Tab，焦點保持在地圖內；Esc 可關閉。驗收過程沒有 JavaScript 例外。
