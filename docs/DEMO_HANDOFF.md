# 2D 固定寫實場景遊戲交接

更新：2026-11-12。主要分支 `main`；本輪功能分支 `feat/2d-wasteland-game`。使用者已改採 2D，不再以 3D／Hunyuan 作為主遊玩流程。

## 遊戲方向

固定場景圖庫 → 故事提供選項 → 玩家選擇 → 後端驗證並保存 → 切換對應背景／Tiled 地圖。原畫的末世寫實與奇幻遺跡風格不變，只降低背景取樣細緻度；先前可愛風格的預覽沒有加入遊戲。

目前六地：平衡議會、命脈之泉、符石林、流塵谷、烈燚原、邊境廢墟。各有地圖、出生點與人物／調查地標。符石林與烈燚原的完整正式設定仍待確認。

## 啟動

本機 Python 3.12、Node 20.9+，根目錄：

```bash
./.venv/bin/pip install -r requirements-dev.txt
./.venv/bin/uvicorn backend.main:app --port 8300
```

另一個終端：

```bash
cd frontend
npm ci
npm run build
npm run start
```

開 <http://localhost:3200>。舊 `/experiments`、`/experiments/babylon` 自動回首頁。此流程不需要 VPN、SSH 或 GPU；不要為展示開啟 Hunyuan 生成。

## 操作與彩排

1. 新旅程由右上 ↺ 確認開始，舊 Session 不刪除。
2. WASD／點地面移動；點人物／地標會走近互動，或近距離按 E。
3. 對話保留文字、麥克風與朗讀；一般聊天不保證推進調查，請選後端發出的行動。
4. M 顯示合法路線與解鎖條件，遠處追蹤先步行接近，再確認出發。
5. J 看手記；回議會後從手記走近維達利亞回報。她只整理實際紀錄。
6. 滾輪／＋－／雙指縮放；手機直向鏡頭會跟隨玩家。Esc 關閉面板。
7. 重整保留場景、回合、配置與線索，但步行位置回目前地點入口。

| 路線 | 可展示內容 |
| --- | --- |
| 火焰 | 議會 → 命脈之泉 → 追查灰燼 → 烈燚原 → 調查長老或聖火 → 返回回報 |
| 風沙 | 議會 → 符石林 → 辨認風沙 → 流塵谷 → 記名或埋葬調查 → 返回回報 |

泉眼也能選裂響去流塵谷，符石林也能選灼熱符痕去烈燚原。同圖可承接不同選擇，結果保存在手記與事件。完成一條調查後可探索另一條；走訪兩地後可前往邊境廢墟，與塞特／希拉交談。走近塞特可協助兩人、通報長老會或暫不介入。協助後 J 背包會取得裂隙地圖及固定圖片，其他兩種結果不發地圖；回訪不能重領。圖書館關卡與其餘中期事件尚未開放。烈燚原另有達索對話，泉眼旁保留維達利亞。

## 程式重點

- `backend/content/scenes.py`：場景 ID、固定圖、Tiled URL、合法路線。
- `frontend/components/MinglinGame.tsx`：背景取樣、人物／landmark、移動、鏡頭。
- `frontend/app/page.tsx`：Session、正式回合、地圖、手記、語音及錯誤同步。
- `frontend/components/InvestigationJournal.tsx`：共用手記，沒有另外複製一套調查邏輯。
- `backend/orchestration/`：Demo 選項、規則 planner 分流、交易前的回合協調。
- `backend/modules/proposal_resolver.py`：操作合法性與效果。
- `backend/database/repository.py`：狀態、事件、對話、NPC 記憶與 action_id 同交易保存。

所有原始場景圖片未修改；顆粒感由背景取樣控制。不要在前端直接發物品、補秘密或硬切場景。2D 不輪詢即時圖片／GLB 工作。

## 驗收與限制

137 個後端測試、既有 12 個前端邏輯測試、production build 通過。Chrome 已實走兩條 2D 路線、四項線索、回報、重整／後端重啟承接、中文輸入法與輸入隔離；新地圖測試包含互動點可達性。證據見 [固定選項與道具 QA](qa/preset-story/README.md)。

目前主情境與 NPC 按鈕均是預寫答案，自由輸入仍走 planner；沒有模型評分器。故事主線仍是規則分支，未接 B 的真實 LLM／RAG。五結局、正式第二／三幕、死亡即結束與完整 NPC 自主行動仍待整合；不能說整個生成式遊戲已完成。
