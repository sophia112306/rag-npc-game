# 2D 固定寫實場景遊戲交接

更新：2026-11-22。主要分支 `main`，不另建立交付分支。使用者已改採 2D，不再以 3D／Hunyuan 作為主遊玩流程。

## 遊戲方向

固定場景圖庫 → 故事提供選項 → 玩家選擇 → 後端驗證並保存 → 切換對應背景／Tiled 地圖。原畫的末世寫實與奇幻遺跡風格不變，只降低背景取樣細緻度；先前可愛風格的預覽沒有加入遊戲。

目前八地：平衡議會、命脈之泉、符石林、流塵谷、烈燚原、邊境廢墟、記憶圖書館、命脈之泉源頭。各有地圖、出生點與人物／調查地標。符石林與烈燚原的完整正式設定仍待確認。

## 啟動

本機 Python 3.12、Node 20.9+，根目錄：

```bash
./.venv/bin/pip install -r requirements-dev.txt
./.venv/bin/uvicorn backend.main:app --port 8300
```

另一個終端：

```bash
cd frontend
npm ci
npm run build
npm run start
```

開 <http://localhost:3200>。舊 `/experiments`、`/experiments/babylon` 自動回首頁。此流程不需要 VPN、SSH 或 GPU；不要為展示開啟 Hunyuan 生成。

## 操作與彩排

1. 新旅程由右上 ↺ 確認開始，舊 Session 不刪除。
2. WASD／點地面移動；點人物／地標會走近互動，或近距離按 E。
3. 對話保留文字、麥克風與朗讀；一般聊天不保證推進調查，請選後端發出的行動。
4. M 顯示合法路線與解鎖條件，遠處追蹤先步行接近，再確認出發。
5. J 看手記；回議會後從手記走近維達利亞回報。她只整理實際紀錄。
6. 滾輪／＋－／雙指縮放；手機直向鏡頭會跟隨玩家。Esc 關閉面板。
7. 重整保留場景、回合、配置與線索，但步行位置回目前地點入口。

| 路線 | 可展示內容 |
| --- | --- |
| 火焰 | 議會 → 命脈之泉 → 追查灰燼 → 烈燚原 → 調查長老或聖火 → 返回回報 |
| 風沙 | 議會 → 符石林 → 辨認風沙 → 流塵谷 → 記名或埋葬調查 → 返回回報 |
| 終局 | 完成兩區 → 邊境廢墟三選一 → 記憶圖書館三層真相 → 塵歸令取捨 → 維塔三問 → 五種結局 |

泉眼也能選裂響去流塵谷，符石林也能選灼熱符痕去烈燚原。同圖可承接不同選擇，結果保存在手記與事件。完成一條調查後可探索另一條；走訪兩地後可前往邊境廢墟，與塞特／希拉交談。走近塞特可協助兩人、通報長老會或暫不介入。協助後 J 背包會取得裂隙拓印圖、餘燼護符與麻布殘片及固定圖片，其他兩種結果不發圖；回訪不能重領。三種結果都能按各自條件前往圖書館，再由真相、關係、塵歸令與篡奪值開放合法終局。烈燚原另有達索對話，泉眼旁保留維達利亞。

## 程式重點

- `backend/content/scenes.py`：場景 ID、固定圖、Tiled URL、合法路線。
- `frontend/components/MinglinGame.tsx`：背景取樣、人物／landmark、移動、鏡頭。
- `frontend/app/page.tsx`：Session、正式回合、地圖、手記、語音及錯誤同步。
- `frontend/components/InvestigationJournal.tsx`：共用手記，沒有另外複製一套調查邏輯。
- `backend/orchestration/`：Demo 選項、規則 planner 分流、交易前的回合協調。
- `backend/modules/proposal_resolver.py`：操作合法性與效果。
- `backend/database/repository.py`：狀態、事件、對話、NPC 記憶與 action_id 同交易保存。

所有原始場景圖片未修改；顆粒感由背景取樣控制。不要在前端直接發物品、補秘密或硬切場景。2D 不輪詢即時圖片／GLB 工作。

## 驗收與限制

自動測試會走完 61 條已編寫故事邊、八份 Tiled 地圖及五種結局；最新精確數量以 README 的當次回歸結果為準。早期 Chrome 六地操作證據仍保留在 [固定選項與道具 QA](qa/preset-story/README.md)，不代表後加終局已做同一輪瀏覽器人工驗收。

目前主情境與 NPC 按鈕均是預寫內容。自由輸入由敘事 AI 判讀數值及少數已編寫的第三幕事件，後端審核後才改狀態，NPC 回覆走既有模型或規則式保底。八位角色的 LoRA 路由與 93 個回覆案例已做真機評測；RAG 只有部分經審核 corpus。五結局可由固定選項流程完成；新夢的關係門檻也有離線對話累積測試。完整 NPC 自主行動與生成式章節仍未完成。

2026-11-28 的第三幕對話事件驗收：第一組「收下塵歸令」合成對話，模型辨識意圖卻回傳 `event_done=null`，後端正確拒絕成立事件。將合法標籤改為 JSON 陣列並在兩輪提示中要求原樣複製後，同一合成句的兩輪模型判讀都回傳「收下塵歸令」，`event_reviewed=true`。再經本機預覽後端與獨立 CPU Gateway 做一次完整 API 回合：HTTP 200、節點前進至 `dust_token_decided`、背包收到塵歸令、關係值 60→70、主軸維持 0。每次驗證均為單一情境、循序呼叫，沒有自動重試；校機原有模型與 Gateway 未重啟，驗收後仍健康。其他事件的真實模型措辭尚未逐一驗收，固定選項仍可完成事件。

補充驗收：模型對「我不會喚醒維塔」正確回傳婉拒事件並通過第二輪；對「維達利亞，我想聽妳的心事，妳願意說給我聽嗎？」則曾漏判、曾只在第二輪挑中，也曾兩輪都漏判。已把明確請求行動的問句寫入提示，並讓後端文字意圖檢查通過的候選一定送第二輪獨立審查；第一輪漏判而第二輪明確選中時可採用，兩輪選出不同事件或第二輪仍未選中時不成立。這仍不能保證模型每次判到同一句話。離線測試確認漏判時事件按鈕保持可用，玩家可用固定選項完成劇情。以上是真實模型抽樣結果，不是所有玩家措辭的品質保證。
