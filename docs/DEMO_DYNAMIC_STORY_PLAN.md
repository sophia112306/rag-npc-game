# 週四動態故事 Demo 實作計畫

目標日期：2026-11-12（週四）  
工作分支：`feature/demo-dynamic-story`  
目標：在沒有 B 的正式模型、RAG 或圖片 API 時仍能完成一條可保存、可分支、可重播的動態故事；外部服務可用時再替換文字與場景圖片，不改寫規則與交易邊界。

## Demo 成功條件

1. 玩家從鳴霖進入遊戲，最多看到四個依目前狀態產生的選項。
2. 不同選項會建立不同的已成立事件、線索、任務或路線，不只是換一句固定台詞。
3. 重新整理或重啟後，故事節點、位置、事件與選項可以接續。
4. 流塵谷與烈燚原只能在後端條件核准後解鎖，不能偽造目的地直接進入。
5. Babylon 3D 會依場景同步改變遠景、地面、前景物件、光線與霧效，不再只替換遠景貼圖。
6. 每次進入場景或成立重大事件後建立圖片工作；前端先顯示已提交資產，生成完成後平滑替換。
7. 圖片服務逾時、拒絕或未設定時使用版本化 fallback，不阻擋文字回合。
8. 所有玩家行動沿用 `action_id`、`state_version`、操作白名單與單一回合交易。

## Demo 故事骨架

故事骨架是規則護欄，不是固定台詞。AI 或規則 fallback 可以生成具體反應，但只能提出後端允許的操作。

1. **鳴霖異象**：玩家向維達利亞確認泉水停滯與世界異象，選擇調查命脈之泉或符石林。
2. **第一條線索**：不同調查地點建立不同來源的線索與 NPC 記憶，並解鎖後續選項。
3. **勢力方向**：玩家可追查聖火／火焰長老方向，或追查墓葬／木乃伊方向；選項只使用原始故事已確認的勢力動機。
4. **特殊場景**：核准事件可解鎖烈燚原；E3-1 與裂隙地圖條件可解鎖流塵谷。兩者都不是普通旅行出口。
5. **Demo 收束**：依已成立事件顯示不同的下一章方向與暫定結局傾向，不在資料不足時直接判定正式五結局。

- 驗收：本文件及進度文件完成，獨立 commit 並推送。

### D1 可保存的故事狀態與選項

- 狀態：`██████████ 100%`。故事進度 schema、玩家安全投影、選項 ID、條件式選項、節點轉移與跨重啟承接均已完成。
- 新增玩家安全的故事進度投影：目前章節、公開線索、可見目標。

- 選項依故事節點、位置、已成立事件與任務動態產生，最多四個。
- 驗收：選不同調查方向得到不同下一組選項；偽造／過期選項拒絕；重啟可接續。

### D2 故事操作與同交易保存

- 狀態：`██████████ 100%`。新增 `advance_story` 白名單操作與後端權威 Demo Story Director，故事節點、公開線索、特殊場景解鎖、事件、位置與對話沿用單一回合交易。
- 新增受控操作：揭露公開線索、推進故事節點、解鎖特殊路線。
- 規則 fallback 與外部 ModelGateway 都只產出 `StoryProposal`。
- 核准事件、位置、故事進度、對話與記憶同交易保存。
- 驗收：重送不重複、版本衝突不覆蓋、失敗不留下半個故事節點。

已完成兩條 fallback 分支：

- 命脈之泉 → 灰燼線索 → 烈燚原 → 聖火／火焰長老方向。

選項文字、目的地或 action 內容遭竄改時回傳 409，過期選項不會推進狀態；重新啟動後故事節點、公開線索、位置與下一組選項仍可接續。

### D4 滾動式圖片生成

- 建立供應商無關 `ImageGateway` 與可持久化 `SceneImageJob`。

- 以故事節點、場景、公開事件及固定 style guide 建立 prompt；不送 NPC 私人記憶。
- 相同 prompt fingerprint 使用快取；每個 Session 限制未完成工作數與重試次數。
- 前端輪詢狀態並在完成後 crossfade；失敗時保留 fallback。
- Demo provider：優先接正式圖片 API；未設定時使用已提交版本化資產，完整流程仍可驗收。
- 驗收：成功、逾時、拒絕、重試、快取、重新整理承接均有測試。

### D5 端到端 Demo

- Chrome 實際操作至少兩條分支，驗證場景、故事、圖片與重啟承接。
- 建立一鍵啟動與 Demo 操作手冊，記錄使用哪個文字／圖片 provider。

## 服務與失敗策略

| 能力 | 正式模式 | Demo fallback | 不可發生 |
| --- | --- | --- | --- |
| 台詞與事件提案 | B 的 ModelGateway／RAG | 有狀態的規則故事導演與選項 | 模型直接改資料庫或核心設定 |
| 規則與結果 | C 的正式規則介面 | A／D 的最小白名單驗證 | 只因台詞聲稱就獲得物品或場景 |
| 場景圖片 | ImageGateway 非同步生成 | 已提交版本化場景資產 | 生圖失敗使正式回合 rollback |
| 3D 顯示 | Scene Profile＋生成圖 | Scene Profile＋fallback 圖 | 只換標題而保留錯誤場景 profile |
